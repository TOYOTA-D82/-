# 第 0 階段：片假名（カタカナ）

片假名跟平假名**發音完全一樣**，只是長相不同。它主要用來寫：

- 外來語：コーヒー（咖啡）、パソコン（電腦）、テレビ（電視）
- 外國人名、地名：アメリカ（美國）、タクシー（計程車）
- 狀聲詞、想強調的字

> 很多人覺得片假名比平假名難記，因為外來語多、字形又硬又像。技巧是：**用外來語單字來記**，比死背字表有效很多。

### 🔍 片假名最容易搞混的字（考試常陷阱）

| 容易混的組合 | 怎麼分辨 |
|---|---|
| **ン (n) / ソ (so)** | ン 的點在左下、由下往上；ソ 的點在上方、由上往下 |
| **シ (shi) / ツ (tsu)** | シ 兩點橫排、末筆由下往上；ツ 兩點直排、末筆由上往下 |
| **ウ (u) / ワ (wa) / フ (fu)** | ウ 上面有點；ワ 左邊開口；フ 只有一筆 |
| **ク (ku) / ケ (ke) / タ (ta)** | 仔細看筆畫數與勾法 |
| **ア (a) / マ (ma)** | マ 是兩筆、下面往下勾 |
| **ラ (ra) / ワ (wa)** | ラ 上面多一橫 |

> シ / ツ 和 ン / ソ 是**所有初學者的惡夢**，一定要多寫幾次，抓住「筆畫方向」的差別。

## 四、片假名特有：長音符號「ー」

片假名的長音**不用多寫母音，直接畫一橫「ー」**（直書時是直線）。

- コーヒー（koohii＝咖啡）
- ラーメン（raamen＝拉麵）
- スーパー（suupaa＝超市）
- ケーキ（keeki＝蛋糕）
