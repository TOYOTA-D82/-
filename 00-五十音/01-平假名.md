# 第 0 階段：平假名（ひらがな）

平假名是日文最基礎的表音文字，**一定要背到看到就能直接唸出來**（像我們看到注音一樣自然）。
建議每天學 2～3 行，搭配手寫，約 1 週可熟。

> 羅馬拼音採用「赫本式（Hepburn）」，這是 JLPT 學習者最通用的標法。

---

## 一、清音（基本 46 音）

| 段 → | a | i | u | e | o |
|---|---|---|---|---|---|
| **あ行** | あ (a) | い (i) | う (u) | え (e) | お (o) |
| **か行** | か (ka) | き (ki) | く (ku) | け (ke) | こ (ko) |
| **さ行** | さ (sa) | し (**shi**) | す (su) | せ (se) | そ (so) |
| **た行** | た (ta) | ち (**chi**) | つ (**tsu**) | て (te) | と (to) |
| **な行** | な (na) | に (ni) | ぬ (nu) | ね (ne) | の (no) |
| **は行** | は (ha) | ひ (hi) | ふ (**fu**) | へ (he) | ほ (ho) |
| **ま行** | ま (ma) | み (mi) | む (mu) | め (me) | も (mo) |
| **や行** | や (ya) | ― | ゆ (yu) | ― | よ (yo) |
| **ら行** | ら (ra) | り (ri) | る (ru) | れ (re) | ろ (ro) |
| **わ行** | わ (wa) | ― | ― | ― | を (wo／o) |
| **鼻音** | ん (n) | | | | |

### ⚠️ 特別注意（最容易唸錯的幾個）

- **し = shi**（不是 si）
- **ち = chi**（不是 ti）
- **つ = tsu**（不是 tu，這個音華語沒有，像「刺」但更短）
- **ふ = fu**（介於 fu 和 hu 之間，嘴唇不咬）
- **を = wo**：現代發音幾乎唸成 o，它只當「受詞助詞」用，不會出現在單字裡。
- **ん = n**：唯一的鼻音，不能單獨當一個字的開頭。

### 🔍 長得很像、容易搞混的字

| 容易混的組合 | 怎麼分辨 |
|---|---|
| **あ (a) / お (o)** | お 右上多一點；あ 沒有 |
| **い (i) / り (ri)** | い 兩筆分開；り 較連貫、右邊往下勾 |
| **は (ha) / ほ (ho)** | ほ 上面多一橫 |
| **れ (re) / ね (ne) / わ (wa)** | ね 右邊有圈圈；わ 右邊直下；れ 右邊往外勾 |
| **る (ru) / ろ (ro)** | る 尾巴有打結；ろ 沒有 |
| **さ (sa) / き (ki)** | き 多一橫（兩橫） |

## 二、濁音（濁點 ゛）

在清音右上加「゛」，發音變濁。

| | i | u | e | o | a |
|---|---|---|---|---|---|
| **が行** | が (ga) | ぎ (gi) | ぐ (gu) | げ (ge) | ご (go) |
| **ざ行** | ざ (za) | じ (**ji**) | ず (zu) | ぜ (ze) | ぞ (zo) |
| **だ行** | だ (da) | ぢ (ji) | づ (zu) | で (de) | ど (do) |
| **ば行** | ば (ba) | び (bi) | ぶ (bu) | べ (be) | ぼ (bo) |

> 註：**じ 和 ぢ 同音（ji）、ず 和 づ 同音（zu）**。現代日文絕大多數用 じ、ず；ぢ、づ 很少見。

## 四、拗音（小さ的 ゃ ゅ ょ）

## 五、長音、促音、鼻音

### 長音（把母音拉長一拍）
平假名用「多一個母音」來表示，**長短會改變意思**，很重要！

- おばさん（obasan＝阿姨） vs おば**あ**さん（obaasan＝奶奶／老太太）
- ゆき（yuki＝雪） vs ゆう**き**（yuuki＝勇氣）
- 規則：a段+あ、i段+い、e段+い或え、o段+う或お、u段+う

### 促音（小寫的 っ）
小寫的「つ」，本身不發音，代表**停頓一拍**（像卡住半秒）。

- きって（kitte＝郵票）→ 唸「ki（停）te」
- がっこう（gakkou＝學校）

### 鼻音 ん
發 n/m/ng 的鼻音，佔一拍。

- ほん（hon＝書）
- せんせい（sensei＝老師）
