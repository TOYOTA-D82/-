## 📱 安裝成 App（PWA）

本專案是 **PWA（漸進式網頁 App）**，可加到手機主畫面，擁有 App 圖示、全螢幕、離線使用。

- 相關檔案：`manifest.json`、`sw.js`（Service Worker 離線快取）、`icon-192.png`／`icon-512.png`／`icon-180.png`
- **安裝方式**
  - iPhone / iPad：用 **Safari** 開啟網站 → 「分享」→「加入主畫面」（**不需要描述檔／.mobileconfig**）
  - Android / Chrome：選單（⋮）→「安裝應用程式」
- **前提**：需以 HTTPS 網址開啟（例如 GitHub Pages）。直接開本機檔案或在沙箱環境中，Service Worker 不會註冊，但功能仍可正常使用。

> 進度（XP、連勝、課程解鎖）存在該裝置瀏覽器的 localStorage，換裝置不會同步。

## 🎮 互動學習網站

打開 `index.html` 就是一個五十音學習小遊戲「**かなクエスト・假名冒險**」，專治三分鐘熱度：

- **總覽首頁**：五十音／單字／文法的學習進度條、一鍵開始
- **學習模式**：五十音（發音＋記憶口訣，點該列下方展開）、單字（清單＋發音）、文法（展開卡看講解與例句）
- **閃卡模式**：翻牌記憶（五十音與單字通用）
- **測驗模式**：選擇題小遊戲，即時對錯、連勝加分、答對蓋「正」印章，支援鍵盤 1–4 作答
  - 五十音：假名↔拼音雙向出題
  - 單字：單字↔中文意思雙向出題
  - 文法：句子填空（選助詞／正確形態）
- **弱點統計**：自動記錄你常認錯的項目，可「只練這些弱點」，並在學習頁用低調小紅點標記
- **設定**：淺色／深色主題、發音開關、重置進度
- **單字闖關課程**：144 字分成 10 課（一課一主題、混合名詞動詞形容詞），**通過該課測驗（答對 80%）才解鎖下一課**，適合一天一課
- **考題（仿真實題型）**：📝 考題分類含漢字読み、語彙選詞、文法、讀解短文（原創題、非官方考古題）；單字測驗也會混入「漢字読み」（看漢字選讀音）提高難度
- **🎧 聽解**：用日語語音出題（即時応答、聞き取り），播放鍵可重聽，題目文字隱藏＝真的用聽的，補上聽力科目
- **內容**：五十音全套；N5 單字 144 字（10 課）；N5 基礎文法 17 條；模擬考題 79 題（漢字読み 26／語彙 22／文法 22／讀解 9）＋聽解 14 題
- **積分／連勝／每日目標／段位**：進度自動存在瀏覽器，讓你想一直回來破紀錄
- **手機優先**：390px 起完整響應式，無水平溢出；資料經程式化逐條驗證（讀音、語意、文法答案唯一性）

> 用法：直接用瀏覽器打開 `index.html` 即可；若要放上網，可用 GitHub Pages 指向這個分支的根目錄。

## 📊 JLPT N5 你需要知道的事實

**題型**（只考「讀」和「聽」，不考口說、不考手寫作文）：
1. 文字・語彙（漢字讀音、單字）
2. 文法・讀解（句型、短文閱讀）
3. 聽解（聽力）

**及格標準**（很重要，決定力氣怎麼分配）：

| 科目 | 配分 | 最低門檻 |
|---|---|---|
| 語言知識（文字語彙・文法）＋ 讀解 | 0～120 | 至少 38 分 |
| 聽解 | 0～60 | 至少 19 分 |
| **總分** | **180** | **及格 80 分** |

**規模**：漢字約 100 字、單字約 800 個、基礎文法。

## 🧭 每天怎麼用（建議流程）

1. **複習**：先花 5 分鐘複習昨天學的（間隔複習最有效）。
2. **新進度**：照當前階段的教材學 15～20 分鐘。
3. **小測**：用練習題檢查自己有沒有真的記住。

> 學語言最怕「三天打魚兩天曬網」。寧可每天 20 分鐘，也不要一週只讀一次 3 小時。
